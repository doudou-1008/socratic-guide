# 三人超详细分工（初学者版）

> 假设三位都是**第一次做项目**的初学者，所以每一步都写得很细。请先读《项目协作手册》和《接口与约定.md》了解整体规则，再按自己名字下的任务做。
> 三个铁律先记住：**① B（组长）主笔《接口与约定.md》定死对接；② Day1 三人一起搭好骨架再写码；③ 共享 Git 仓库，小步提交。**

## 开工前（Day 0–1，三人一起做）

> ⚠️ **第一步先搞定 GitHub**，否则后面代码没地方提交。

**1. 每个人都要注册 GitHub 账号**
浏览器打开 github.com → 点 **Sign up** → 填用户名/邮箱/密码 → 去邮箱点验证链接激活。**A、B（组长）、C 三人每人一个账号**，这是后面提交代码的硬性前提。

**2. 组长 B 建仓库，并把 A、C 拉进来**
- B 登录 GitHub → 右上角 `+` → **New repository** → 仓库名 `socratic-guide` → 选 **Public** → 勾选 **Add a README file** → **Create repository**。
- 进仓库 **Settings → Collaborators（新版在 Access）→ Add people**，分别输入 **A、C 的 GitHub 用户名或邮箱** 发邀请。
- A、C 到自己 GitHub 通知 / 邮箱里点 **Accept invite**，就成为协作者，拥有提交权限。
- 三人各自在电脑上：点仓库绿色 **Code** 按钮复制地址 → 终端 `git clone https://github.com/<B 的用户名>/socratic-guide.git`。
- *说明：仓库建在 B 账号下即可；想挂团队组织也行，B 先建 GitHub Organization 再建仓库、邀请三人。*

**3. B 主笔《接口与约定.md》**
B 根据《接口与约定.md》初稿，和 A、C 逐条确认字段，定稿后 A、C 才能开始写接口/页面。文档放 `docs/` 文件夹，以后改接口必须先改它再写码。

**4. 装软件**：每人电脑装 Python 3.11、Git（上一步 clone 要用它）；Node.js（LTS）可选装（前端起服备用）。AI 助手用 **Cursor / Trae / CodeBuddy 任意一种**，不强制统一。

**5. 搭骨架**：三人一起按手册 §3 建好 `backend/`、`frontend/`、`docs/` 空文件夹和空文件。

**6. 统一工具**：都用手册 §2 的版本，别自己换框架。

**具体做什么**

4. 把下面"用 Vibe Coding 怎么做"的提示词发给 Cursor，让它生成代码。
5. 新建 `.env` 文件（文件名前面有个点），里面写：`DEEPSEEK_API_KEY=你复制的Key`。
6. 打开终端（Cursor 里按 `Ctrl`+`` ` `` 反引号），依次输入：建虚拟环境、装依赖、启动。
7. 浏览器打开 `http://127.0.0.1:8000/docs`，找到 `/chat`，点 Try it out，输入一句话测试，看是否返回 AI 回复。
8. 能返回就成功；报错就把红色报错复制给 Cursor 说"运行报这个错，帮我修"。

**产出**：一个能跑的 `/chat` 接口，打开 `/docs` 能测通。

# 附：Git 小步提交（初学者手把手）

> 共享仓库，别最后一次性 push。每天完成一个小任务就提交。

```bash
# 1. 第一次：克隆仓库（只做一次）
git clone https://github.com/组长B的用户名/socratic-guide.git
cd socratic-guide

# 2. 开新分支做任务（别直接改 main）
git checkout -b feature/A-chat

# 3. 改完代码后，添加并提交（每完成一个小功能就做这两步）
git add backend/main.py
git commit -m "feat: A 完成 /chat 基础接口"

# 4. 推到 GitHub
git push origin feature/A-chat

# 5. 在 GitHub 上发 Pull Request 到 main，组长 B 审核合并
```

**commit 规范**：`feat:` 新功能 / `fix:` 修 Bug / `docs:` 文档 / `refactor:` 重构，后面跟简短中文说明。

# 附：代码怎么跑起来（速查）

**后端（A，Windows）**
```bash
cd backend
python -m venv venv
.\venv\Scripts\activate          # 注意反斜杠、Scripts
pip install -r requirements.txt
copy .env.example .env          # 填入 DEEPSEEK_API_KEY
uvicorn main:app --reload       # 跑在 http://127.0.0.1:8000
```
浏览器开 `http://127.0.0.1:8000/docs` 测 /chat。

**前端（B，二选一）**
```bash
cd frontend
python -m http.server 3000      # 推荐，零额外安装
# 或： npm run serve
```
`js/chat.js` 请求地址写 `http://127.0.0.1:8000/chat`。

**联调（C）**：开 `http://127.0.0.1:3000`，输入"我的代码报错了"，看 AI 是否只提问不回答；测切赛道进度不丢。

> 常见问题：Redis 不用装（用 sqlite/字典）；Key 绝不提交；前端必须用 `python -m http.server 3000` 或 `npx serve` 起，不能直接双击打开 html（ES Module 会跨域失败）；SSE 用 `fetch` 读，别用 EventSource。
