苏格拉底项目 · 后端上手保姆教程（给 A）
=====================================
你是成员 A，负责「后端」——也就是这个 AI 导师的「大脑」。
前端（界面）B 已经做好了，现在只要你的后端能跑起来、能回答，整个产品就活了。
这份教程从「你电脑上什么都没有」开始写，每一步都有能直接复制的命令。
不用懂原理，照着做就行；卡住了看最后「新手最常卡的 5 个坑」。

------------------------------------------------------------
零、先记住三件事
------------------------------------------------------------
1. 后端跑在本机 8000 端口；前端跑在 5500 端口。两个都要开。
2. 没配 DeepSeek 的 Key 也能跑，会自动进入「演示模式」（回答是假的模板，但流程是通的，方便你先验证）。
3. 所有 Key、密码都只填在 .env 文件里，这个文件不会进 Git，放心。

------------------------------------------------------------
一、第一次只需装一次的工具
------------------------------------------------------------
（下面两条装过就不用再装，换电脑才需要重来）

1）装 Python（选 3.10 以上版本）
   - 打开浏览器搜「Python 官网」或直接访问 python.org
   - 点 Download Python 3.x.x，下载完双击安装
   - 【关键】安装界面最下面有个「Add python.exe to PATH」的勾，一定要打勾！
   - 装完验证：打开「命令提示符」（Windows 键搜 cmd），输入：
        python --version
     回车后如果显示 Python 3.x.x 就成功了。
     （如果显示「不是内部或外部命令」，就是 PATH 没勾上，重装一次补勾）

2）装 Git
   - 浏览器搜「Git 官网」或访问 git-scm.com
   - 下载 64-bit Git for Windows，一路下一步装完
   - 验证：cmd 里输入：
        git --version
     显示 git version x.x.x 就成功。

------------------------------------------------------------
二、拿到项目代码
------------------------------------------------------------
（如果 B 已经让你 clone 过了、并且里面有 backend 文件夹，跳过这步）

1）cmd 里进你想放代码的目录，比如桌面：
        cd Desktop

2）把仓库拉下来：
        git clone https://github.com/doudou-1008/socratic-guide.git

3）进项目、再进后端目录：
        cd socratic-guide
        cd backend

   以后每次打开 cmd 干活，都要先 cd 到这个 backend 目录。

------------------------------------------------------------
三、第一步：把后端先跑起来（演示模式，不用 Key）
------------------------------------------------------------
这一步的目标：确认你的环境能跑，打开一个能看的网页。

1）在 backend 目录里，建一个独立的 Python 小环境（叫虚拟环境，避免把你电脑其他 Python 搞乱）：
        python -m venv venv

2）激活这个小环境：
        venv\Scripts\activate
   （激活后，命令行最前面会出现 (venv) 字样，表示成功。
    如果你用的是 Git Bash 而不是 cmd，命令改成：
        source venv/Scripts/activate  ）

3）装项目需要的包（只需第一次）：
        pip install -r requirements.txt
   如果装得很慢或卡住，用国内镜像加速：
        pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

4）启动后端：
        uvicorn main:app --reload
   看到屏幕一直刷出类似「Uvicorn running on http://127.0.0.1:8000」就成功了，
   这个窗口先别关。

5）验证：打开浏览器访问
        http://127.0.0.1:8000/docs
   能看到一个写着「FastAPI」的网页，里面有 /chat、/session 两个接口，就说明后端活了。

   （现在不配 Key，回答会是「演示模式」模板，这是正常的。）

------------------------------------------------------------
四、配 DeepSeek 的 Key（让导师「真会答」）
------------------------------------------------------------
1）申请 Key：
   - 浏览器搜「DeepSeek 开放平台」或访问 platform.deepseek.com
   - 注册 → 充值一点钱（新人有免费额度，比赛够用）→ 找到「API Keys」点「创建密钥」
   - 复制那一长串 sk- 开头的字符串（只显示一次，存好）

2）在 backend 目录里，把 .env.example 复制一份，改名为 .env
   （cmd 里：  copy .env.example .env   ）
   用记事本打开 .env，改成下面这样（只改等号后面的值）：
        DEEPSEEK_API_KEY=sk-你刚才复制的那串
        JUDGE0_API_KEY=
        CORS_ORIGINS=http://127.0.0.1:3000,http://127.0.0.1:5500
   【注意】CORS_ORIGINS 里一定要带上 5500，这是前端跑的端口，不写等会儿联调会被浏览器拦。

3）回到跑着 uvicorn 的那个窗口，按 Ctrl+C 停掉，再重新运行一次：
        uvicorn main:app --reload
   现在后端就读到 Key 了。访问 http://127.0.0.1:8000/ ，
   如果显示 "model": "deepseek-chat" 就说明真模型已接入；
   还显示 mock(演示模式) 就是 Key 没生效（看最后「坑 3」）。

------------------------------------------------------------
五、和 B 的前端联调
------------------------------------------------------------
你负责后端，B 负责前端。联调时两边要能互相访问。

- 你这边要做的：保证后端 8000 在跑，且 .env 的 CORS_ORIGINS 包含了前端端口（5500）和以后部署的域名。这步第四步已经做了。
- B 那边要做的：B 会把前端里的后端地址改成你的地址（本地联调就填 http://127.0.0.1:8000，部署后就填你的线上域名）。这个 B 来改，你不用动前端。
- 联调验证：B 在浏览器发一条消息，如果右边聊天区开始一个字一个字冒出回答，就成功了。如果 B 那边报「CORS」「跨域」红色错误，就是 CORS_ORIGINS 没配对，回去第四步检查。

------------------------------------------------------------
六、加「日常闲聊」赛道（T2，具体改两处代码）
------------------------------------------------------------
前端已经多了这个赛道，但你的后端现在还不认它（会返回 400 错误）。需要你加。
改完这两处，重新 uvicorn 一下就好。

改动 1：文件 backend/main.py 第 29 行附近
   找到这一行：
        TRACK_ENUMS = ["programming", "thesis", "habit"]
   改成（多了 "daily"）：
        TRACK_ENUMS = ["programming", "thesis", "habit", "daily"]

改动 2：文件 backend/prompts.py
   在 TRACKS 这个大字典里，找到 habit 那一段结束的 "}," 和整个字典结尾的 "}" 之间，
   插入下面这段（直接复制粘贴，注意缩进对齐其他赛道）：

    "daily": {
        "name": "日常闲聊",
        "color": "#db2777",
        "stages": [
            {"stage": 1, "label": "说清琐事"},
            {"stage": 2, "label": "厘清想法"},
            {"stage": 3, "label": "自己定夺"},
        ],
        "system": (
            "你是一位苏格拉底式的日常闲聊伙伴。你的唯一任务是通过提问陪用户理清生活里的小纠结，"
            "绝对不直接替用户做决定或给现成答案。\n"
            "原则：\n"
            "1) 只提问，引导用户自己把琐事说清楚、把想法理明白、最后自己定夺；\n"
            "2) 用户若说'直接告诉我答案'，你必须回答：'我不能直接给你答案，但我可以给你一个提示。'；\n"
            "3) 顺着'说清琐事→厘清想法→自己定夺'推进，一次只问一个关键问题；\n"
            "4) 语气轻松、像朋友闲聊，但仍保持苏格拉底式只问不答；\n"
            "5) 用中文。\n"
        ),
    },

   插好之后，TRACKS 里就有 programming、thesis、habit、daily 四项了。

（可选）改动 3：文件 backend/knowledge.json
   在最外层大括号里、habit 那段结束后加一个 daily 条目，让 RAG 能检索到生活类提示。
   不加也不会报错（代码里没有 daily 就返回空），加了回答更聪明：

  "daily": [
    {"keywords": ["买", "纠结", "选"], "hint": "引导用户先说清真正在意的是价格、需求还是别人眼光"},
    {"keywords": ["回消息", "人际关系", "朋友"], "hint": "引导用户厘清自己在这段关系里真正想要什么"},
    {"keywords": ["焦虑", "内耗", "想不通"], "hint": "引导用户把模糊的情绪拆成一件具体的、能想清楚的小事"}
  ]

验证：重新 uvicorn 启动，在 http://127.0.0.1:8000/docs 里点 /chat，
   选 track 填 daily、随便写条 message、user_id 填个假 id（比如 abc），
   点 Execute，能看到流式回答就成功了。

------------------------------------------------------------
七、多会话对接（T4，进阶，先把前面跑通再做）
------------------------------------------------------------
现状：前端现在每条赛道可以建很多条独立对话，但你的后端目前按「(user_id, track)」只存一份历史，
   所有对话会混在一起。前端发消息时其实带了 conversation_id，你后端现在没用它。

改法方向（等第六步跑通后再做）：
   1) 把数据库表 session 的主键，从 (user_id, track) 改成 (user_id, track, conversation_id)
   2) load_session / save_session 两个函数都加一个 conversation_id 参数
   3) /chat 和 /session 两个接口，从请求里读出前端传来的 conversation_id（前端一定带了），
      传给上面两个函数
   这样每条对话就各存各的、互不干扰了。

（这步不影响「能不能演示」，可以等联调没问题了再补。）

------------------------------------------------------------
八、国内部署（T5，最后做，让评委能访问）
------------------------------------------------------------
比赛要给评委一个能打开的网址，不能用你本机 8000。
用国内平台（阿里云函数计算 FC / 轻量服务器 ECS 都行），不要放 Vercel、Railway（国内评委可能打不开）。
部署时把 .env 里的 DEEPSEEK_API_KEY 和 CORS_ORIGINS 填好（CORS_ORIGINS 写你部署后的前端域名）。
具体部署步骤等前面都通了，B 会和你一起定，不急。

------------------------------------------------------------
九、新手最常卡的 5 个坑
------------------------------------------------------------
坑 1：端口 8000 被占用，uvicorn 起不来
   解决：换端口跑，比如 uvicorn main:app --reload --port 8080；或关掉占端口的程序。

坑 2：pip install 报「找不到包 / 找不到模块」
   原因：你忘了先激活虚拟环境（命令行前面没 (venv)）。
   解决：先 venv\Scripts\activate，再 pip install。

坑 3：配了 Key 还是显示 mock(演示模式)
   检查三处：
     - .env 文件名对不对（就叫 .env，不是 .env.example，也不是 .env.txt）
     - DEEPSEEK_API_KEY= 后面有没有真的 sk- 开头那串，没多空格
     - 改完 .env 有没有重启 uvicorn（Ctrl+C 再跑一次）

坑 4：浏览器报 CORS / 跨域错误（红字）
   原因：.env 的 CORS_ORIGINS 没包含前端端口。
   解决：CORS_ORIGINS 里加上 http://127.0.0.1:5500，重启 uvicorn。

坑 5：pip 装得极慢或总超时
   解决：用国内镜像
        pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

------------------------------------------------------------
十、建议你按这个节奏做（不用一天干完）
------------------------------------------------------------
第 1 天：做完「一、二、三」——把后端演示模式跑起来，能打开 /docs 网页。
第 2 天：做「四」——配上 DeepSeek Key，确认 / 页面显示 deepseek-chat。
第 3 天：做「六」——加上 daily 赛道，在 /docs 里测通 daily 对话。
         顺便确认「五」的 CORS 已配好，等 B 那边联调。
之后：和 B 联调 → 有空再做「七」多会话 → 最后「八」部署。

有任何一步卡住，把屏幕上的报错文字发群里，B 或我帮你盯。
