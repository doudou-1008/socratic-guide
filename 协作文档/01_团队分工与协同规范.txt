------------------------------------------------------------
一、项目一句话
------------------------------------------------------------
一个「只提问、不回答」的 AI 导师网站，覆盖 4 个赛道：
  编程排错 / 论文写作 / 自律习惯 / 日常闲聊
用户遇问题，AI 不直接给答案，而是用追问引导他自己想明白。

------------------------------------------------------------

------------------------------------------------------------
- A（后端）：做「大脑」—— backend/ 文件夹。
  让 AI 真能回答、接 daily 赛道、修跨域、后面做多会话和部署。
- B（前端 + 组长）：做「脸面」+ 协调—— frontend/ 文件夹、本协作文档、README。
  界面已基本做完。
- C（文档视频）：做「路演材料」—— PPT 文案、测试清单、演示视频。不写代码。

四、怎么一起干活（协同流程）
------------------------------------------------------------
1. 代码放 GitHub：doudou-1008/socratic-guide，main 分支。
2. 小步提交：改一点就 commit + push + 发 PR 给 B 合并；
   别攒一大坨最后一次推。
3. 提交格式：feat: 新功能 / fix: 修 bug / docs: 文档 / refactor: 重构。
4. 接口不能乱改：前后端对接字段写在 04_接口与约定.md，
   要改先改文档、三人确认再写码。
5. 卡住就把报错文字发群里，B 或其他成员帮你看。

------------------------------------------------------------
六、给新人的提醒
------------------------------------------------------------
- 前端必须用 http 起服务看（python -m http.server 5500），
  双击 html 会白屏（ES 模块限制）。
- 后端没配 Key 也能跑（演示模式），先跑通再接真模型。
- 所有密码 Key 只填 backend/.env，这个文件不会进 Git。
- 部署只用国内平台（EdgeOne Pages / 阿里云），
  别用 Vercel / Railway（评委可能打不开）。
- 项目完整说明见本文件夹 00_项目总览与协同说明.md，读完即可掌握项目全貌与对接要点。

有任何一步拿不准，发群里。你这块不靠写代码也能推进，是最稳的一环。
